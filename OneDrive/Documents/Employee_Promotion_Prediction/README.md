# Employee Promotion Prediction

A Machine Learning application that predicts employee promotion likelihood using employee performance and other relevant attributes.

## Live Demo
https://employee-promo-2026.streamlit.app/

## GitHub Repository
https://github.com/poojithmudigolam27-del/Employee_Promotion_Prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Streamlit

## Features
- Individual employee promotion prediction
- Batch prediction using CSV upload
- Promotion probability display
- Model performance metrics
- Download prediction results as CSV

## Model Performance
- Accuracy: 88.61%
- Balanced Accuracy: 75.83%
- ROC-AUC: 0.8873
- Promotion Recall: 59.85%
- Promotion Precision: 44.78%
- Promotion F1-score: 0.5123

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
